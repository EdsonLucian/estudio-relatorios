ATUALIZAR NO GITHUB
1. Salve o backup do relatório em edição.
2. Extraia este ZIP. Abra a pasta onde está index.html.
3. No repositório, abra Code > Add file > Upload files.
4. Arraste TODO o conteúdo da pasta (arquivos e subpastas) para a raiz.
5. Confirme a substituição com Commit changes.
6. Aguarde Actions > pages build and deployment ficar verde.
7. Abra seu site e pressione Ctrl+F5.
